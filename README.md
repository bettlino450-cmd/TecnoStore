# TecnoStore

Sistema web para la gestión de productos y pedidos de una tienda de tecnología, desarrollado como proyecto académico utilizando Angular.

## Descripción

TecnoStore permite consultar productos, registrar pedidos y administrar el historial de compras. La información se almacena en el navegador mediante IndexedDB.

## Tecnologías utilizadas

- Angular 19.2.27
- TypeScript
- HTML5 y CSS3
- Bootstrap
- IndexedDB

## Funcionalidades principales

- Visualización de productos disponibles.
- Búsqueda y filtrado de productos por categoría.
- Registro de pedidos con validaciones.
- Actualización automática del stock.
- Historial de pedidos registrados.
- Consulta del detalle de cada pedido.
- Cancelación de pedidos y restauración del stock.
- Almacenamiento local de datos mediante IndexedDB.

## Requisitos

- Node.js
- npm
- Angular CLI 19.2.27

## Instalación y ejecución

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/bettlino450-cmd/TecnoStore.git
   ```

2. Ingresar a la carpeta:

   ```bash
   cd TecnoStore
   ```

3. Instalar las dependencias:

   ```bash
   npm install
   ```

4. Ejecutar el servidor de desarrollo:

   ```bash
   ng serve
   ```

5. Abrir en el navegador:

   `http://localhost:4200/`

## Compilación

Para generar la versión de producción:

```bash
ng build
```
